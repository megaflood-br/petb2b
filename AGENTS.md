# AGENTS.md

Guidance for AI coding agents working in this repository.

## Testing & demonstration preferences

- Do **not** produce screenshot or video walkthrough demonstrations for this
  project by default. Skip GUI/computer-use recordings, saved screenshots, and
  video artifacts unless the user **explicitly** asks for them in the request.
- Still verify changes work (e.g. via terminal commands, HTTP checks, or
  automated tests), but present the evidence as concise text/logs rather than
  images or videos.
- When the user does explicitly request a print (screenshot) or video, produce
  it as usual.

_(Preferência em português: por padrão, NÃO gerar demonstrações com prints ou
vídeos neste projeto — apenas quando o usuário solicitar explicitamente.)_
